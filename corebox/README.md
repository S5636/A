# COREBOX

자주 쓰는 서류(사업자등록증, 신고증, 통장사본, 연도별 세금 서류 등)를
한 곳에 모아두고 필요할 때 바로 다운받는 서류 보관함입니다. 소득금액증명
처럼 숫자가 있는 서류는 "집계용 문서 종류"만 적어두면 연도별로 자동
합산해서 보여줍니다.

## 실행 방법

### Windows - 더블클릭으로 실행 (권장)

`START.bat`을 더블클릭하면 설치 → 서버 시작 → 브라우저 열기까지 자동으로 됩니다.
콘솔 창에 뜨는 두 주소 중,

- `http://127.0.0.1:5051` - 이 PC 자체에서 볼 때
- `http://<사설 IP>:5051` - **같은 와이파이에 연결된 폰**에서 볼 때 (폰 브라우저에 이 주소를 입력)

올린 서류 파일은 `uploads/` 폴더에, 등록 정보는 `corebox.db`에 저장됩니다.
둘 다 이 PC에만 있고 깃허브에는 올라가지 않습니다.
