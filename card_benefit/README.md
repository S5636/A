# 카드 남은혜택 체크

카드마다 붙어있는 월 한도 혜택(스타벅스 할인, 대중교통 캐시백 등)을 등록해두고,
이번 달 얼마나 썼는지 / 얼마나 남았는지를 PC와 폰이 같이 보고 같이 기록하는
공용 웹앱입니다.

## 실행 방법

### Windows - 더블클릭으로 실행 (권장)

`START.bat`을 더블클릭하면 설치 → 서버 시작 → 브라우저 열기까지 자동으로 됩니다.
콘솔 창에 뜨는 두 주소 중,

- `http://127.0.0.1:5050` - 이 PC 자체에서 볼 때
- `http://<사설 IP>:5050` - **같은 와이파이에 연결된 폰**에서 볼 때 (폰 브라우저에 이 주소를 입력)

를 사용하면 됩니다. 이 창을 닫으면 서버가 종료됩니다.

### 직접 명령어로 실행

```bash
pip install -r requirements.txt
python app.py
```

기본 포트는 `5050`이며, `PORT` 환경변수로 바꿀 수 있습니다.

## 사용법

1. **카드 추가** - 카드 이름과 "혜택 초기화 기준일"(보통 결제일 또는 매월 1일)을 입력합니다.
2. 카드 안에서 **+ 혜택 추가**로 월 한도 혜택을 등록합니다. (금액 한도 또는 횟수 한도 선택 가능)
3. 혜택을 실제로 쓴 날 **사용 기록** 버튼으로 사용 금액/횟수를 남기면, 남은 혜택이 자동으로 줄어듭니다.
4. 남은 혜택은 초록(여유) → 주황(80% 이상 사용) → 빨강(한도 초과) 순서로 표시됩니다.
5. 혜택 초기화 기준일이 지나면 사용량이 자동으로 새 사이클로 리셋됩니다(과거 기록은 "내역"에서 계속 볼 수 있어요).

## 파일 구조

```
app.py              Flask 서버 (라우트 + 잔여혜택 계산)
models.py           SQLite 스키마 + 혜택 사이클(초기화 주기) 계산
templates/index.html
static/css/style.css
static/js/app.js
card_benefit.db      카드/혜택/사용기록 데이터 (최초 실행 시 자동 생성)
launcher.py, START.bat   Windows 더블클릭 실행용
```

## 데이터 백업 / 다른 PC로 옮기기

`card_benefit.db` 파일 하나만 복사하면 모든 카드/혜택/사용기록이 그대로 옮겨집니다.
