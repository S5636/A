# 카드 남은혜택 체크

카드마다 붙어있는 월 한도 혜택(스타벅스 할인, 대중교통 캐시백 등)을 등록해두고,
이번 달 얼마나 썼는지 / 얼마나 남았는지를 PC와 폰이 같이 보고 같이 기록하는
공용 웹앱입니다.

## 실행 방법

### Windows - 더블클릭으로 실행 (권장)

`START.bat`을 더블클릭하면 설치 → 서버 시작 → 브라우저 열기까지 자동으로 됩니다.
콘솔 창에 뜨는 두 주소 중,

- `http://127.0.0.1:5050` - 이 PC 자체에서 볼 때
- `http://<사설 IP>:5050` - **같은 와이파이에 연결된 폰**에서 볼 때 (폰 브라우저에 이 주소를 입력)

를 사용하면 됩니다. 이 창을 닫으면 서버가 종료됩니다.

### 직접 명령어로 실행

```bash
pip install -r requirements.txt
python app.py
```

기본 포트는 `5050`이며, `PORT` 환경변수로 바꿀 수 있습니다.

## 사용법

1. **카드 추가** - 카드 이름과 "혜택 초기화 기준일"(보통 결제일 또는 매월 1일)을 입력합니다.
2. 카드 안에서 **+ 혜택 추가**로 월 한도 혜택을 등록합니다. (금액 한도 또는 횟수 한도 선택 가능)
3. 혜택을 실제로 쓴 날 **사용 기록** 버튼으로 사용 금액/횟수를 남기면, 남은 혜택이 자동으로 줄어듭니다.
4. 남은 혜택은 초록(여유) → 주황(80% 이상 사용) → 빨강(한도 초과) 순서로 표시됩니다.
5. 혜택 초기화 기준일이 지나면 사용량이 자동으로 새 사이클로 리셋됩니다(과거 기록은 "내역"에서 계속 볼 수 있어요).

## 결제 알림 자동수집 (수동 입력 줄이기)

매번 직접 입력하기 번거로우면, 카드 결제 승인 알림(문자 또는 카드사 앱 푸시 알림)을
**MacroDroid**(무료 안드로이드 자동화 앱, Play 스토어에서 설치)로 자동으로 이 앱에
보내도록 설정할 수 있습니다. 완전 자동으로 어떤 혜택인지까지 판단하진 못하고,
**"금액은 자동으로 채워지고, 어떤 혜택인지만 탭 한 번으로 골라주는"** 방식입니다.

1. 앱 상단의 **🔔 자동수집 설정**을 눌러 웹훅 주소(토큰 포함)를 확인합니다.
2. 카드 등록/수정 화면에서 **카드 뒤 4자리**를 입력해두면, 알림이 왔을 때 어떤 카드인지
   자동으로 매칭해줍니다.
3. 폰에 MacroDroid를 설치하고 매크로를 하나 만듭니다.
   - **트리거**: `Notification Received` → 신한 SOL페이 등 카드 결제 알림이 오는 앱을 선택
     (문자로 오는 카드라면 `SMS Received` 트리거를 대신 사용)
   - **액션**: `HTTP Request` (또는 `Web Request`)
     - Method: `POST`
     - URL: 자동수집 설정 화면에서 복사한 주소 (`.../api/inbox?token=...`)
     - Content-Type: `application/json`
     - Body: `{"text": "[notification_text]"}` (알림 원문을 그대로 넣는 매크로 변수 사용)
   - 참고: 폰이 집 와이파이가 아니라 데이터망에 있을 때는 PC 서버에 접속이 안 되니,
     그럴 땐 요청이 실패합니다(카드 등록/사용기록 자체는 나중에 와이파이에서 수동으로 채워도 됨).
4. 이후 결제할 때마다 알림이 오면 자동으로 "받은 결제 알림" 목록에 쌓이고,
   앱을 열어 **혜택 선택**만 누르면 사용 기록이 완성됩니다.
5. 토큰이 유출된 것 같으면 자동수집 설정 화면에서 **토큰 재발급**을 누르고
   MacroDroid의 URL도 새 주소로 바꿔주세요.

카드사 알림 문구가 제각각이라 금액/가맹점 자동 인식이 완벽하지 않을 수 있습니다
(그럴 땐 배정 화면에서 금액을 직접 고쳐서 저장하면 됩니다).

## 파일 구조

```
app.py              Flask 서버 (라우트 + 잔여혜택 계산 + 알림 자동수집 API)
models.py           SQLite 스키마 + 혜택 사이클(초기화 주기) 계산 + 알림 텍스트 파싱
templates/index.html
static/css/style.css
static/js/app.js
card_benefit.db      카드/혜택/사용기록 데이터 (최초 실행 시 자동 생성)
launcher.py, START.bat   Windows 더블클릭 실행용
```

## 데이터 백업 / 다른 PC로 옮기기

`card_benefit.db` 파일 하나만 복사하면 모든 카드/혜택/사용기록이 그대로 옮겨집니다.
