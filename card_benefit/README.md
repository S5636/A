# 카드 남은혜택 체크

카드마다 붙어있는 월 한도 혜택(스타벅스 할인, 대중교통 캐시백 등)을 등록해두고,
이번 달 얼마나 썼는지 / 얼마나 남았는지를 PC와 폰이 같이 보고 같이 기록하는
공용 웹앱입니다.

## 실행 방법

### Windows - 더블클릭으로 실행 (권장)

`START.bat`을 더블클릭하면 설치 → 서버 시작 → 브라우저 열기까지 자동으로 됩니다.
콘솔 창에 뜨는 두 주소 중,

- `http://127.0.0.1:5050` - 이 PC 자체에서 볼 때
- `http://<사설 IP>:5050` - **같은 와이파이에 연결된 폰**에서 볼 때 (폰 브라우저에 이 주소를 입력)

를 사용하면 됩니다. 이 창을 닫으면 서버가 종료됩니다.

### 직접 명령어로 실행

```bash
pip install -r requirements.txt
python app.py
```

기본 포트는 `5050`이며, `PORT` 환경변수로 바꿀 수 있습니다.

## 사용법

1. **카드 추가** - 카드 이름과 "혜택 초기화 기준일"(보통 결제일 또는 매월 1일)을 입력합니다.
2. 카드 안에서 **+ 혜택 추가**로 월 한도 혜택을 등록합니다. (금액 한도 또는 횟수 한도 선택 가능)
3. 혜택을 실제로 쓴 날 **사용 기록** 버튼으로 사용 금액/횟수를 남기면, 남은 혜택이 자동으로 줄어듭니다.
4. 남은 혜택은 초록(여유) → 주황(80% 이상 사용) → 빨강(한도 초과) 순서로 표시됩니다.
5. 혜택 초기화 기준일이 지나면 사용량이 자동으로 새 사이클로 리셋됩니다(과거 기록은 "내역"에서 계속 볼 수 있어요).

## 전월실적 체크

많은 카드는 "전월 OO만원 이상 써야 이번 달 혜택이 적용된다"는 조건이 있습니다. 카드 등록/수정
화면에서 **전월실적 기준금액**을 입력해두면, 카드 위에 이번 달 누적 사용액과 함께
**실적 충족(초록)/실적 부족(빨강)** 배지가 표시됩니다.

- "수정" 링크를 눌러 카드사 앱/문자로 확인한 "이번 달 이용금액"을 그대로 입력하면 됩니다
  (특정 혜택에 안 걸리는 일반 결제까지 포함한 전체 사용액 기준입니다).
- 기준금액을 비워두면(0) 그 카드는 실적 조건이 없는 걸로 보고 배지가 아예 안 뜹니다.
- 이 배지는 **이번 달 지금까지 쌓인 실적**을 보여주는 것으로, "이번 달 실적을 채우면 다음 달
  혜택이 열린다"는 걸 미리 확인하기 위한 용도입니다. (카드사 앱에 뜨는 "실적 부족" 표시는
  보통 "지난달 실적으로 이번 달 혜택이 열렸는지"를 보여주는 것이라 시점이 다를 수 있습니다 -
  헷갈리지 않게 참고하세요.)

## 결제 알림 자동수집 (수동 입력 줄이기)

매번 직접 입력하기 번거로우면, 카드 결제 승인 알림(문자 또는 카드사 앱 푸시 알림)을
**MacroDroid**(무료 안드로이드 자동화 앱, Play 스토어에서 설치)로 자동으로 이 앱에
보내도록 설정할 수 있습니다. 완전 자동으로 어떤 혜택인지까지 판단하진 못하고,
**"금액은 자동으로 채워지고, 어떤 혜택인지만 탭 한 번으로 골라주는"** 방식입니다.

1. 앱 상단의 **🔔 자동수집 설정**을 눌러 웹훅 주소(토큰 포함)를 확인합니다.
2. 카드 등록/수정 화면에서 **카드 뒤 4자리**를 입력해두면, 알림이 왔을 때 어떤 카드인지
   자동으로 매칭해줍니다.
3. 폰에 MacroDroid를 설치하고 매크로를 하나 만듭니다.
   - **트리거**: `Notification Received` → 신한 SOL페이 등 카드 결제 알림이 오는 앱을 선택
     (문자로 오는 카드라면 `SMS Received` 트리거를 대신 사용)
   - **액션**: `HTTP Request` (또는 `Web Request`)
     - Method: `POST`
     - URL: 자동수집 설정 화면에서 복사한 주소 (`.../api/inbox?token=...`)
     - Content-Type: `application/json`
     - Body: `{"text": "[notification_text]"}` (알림 원문을 그대로 넣는 매크로 변수 사용)
   - 참고: 폰이 서버 PC와 같은 와이파이에 있어야 요청이 성공합니다. 데이터망(LTE/5G)에
     있을 때는 실패합니다.
4. 이후 결제할 때마다 알림이 오면 자동으로 "받은 결제 알림" 목록에 쌓이고,
   앱을 열어 **혜택 선택**만 누르면 사용 기록이 완성됩니다.
5. 토큰이 유출된 것 같으면 자동수집 설정 화면에서 **토큰 재발급**을 누르고
   MacroDroid의 URL도 새 주소로 바꿔주세요.

카드사 알림 문구가 제각각이라 금액/가맹점 자동 인식이 완벽하지 않을 수 있습니다
(그럴 땐 배정 화면에서 금액을 직접 고쳐서 저장하면 됩니다).

### 집/회사처럼 와이파이가 두 곳일 때

웹훅 주소에 들어있는 IP는 "지금 이 폰이 연결된 네트워크 기준"으로 자동 생성됩니다.
서버 PC가 항상 같은 곳(예: 집)에 있고 폰만 왔다갔다 한다면, 폰이 집 와이파이일 때만
자동수집이 되고 회사에 있을 때는 안 됩니다(그때 결제한 내역은 나중에 엑셀 업로드나
수동 입력으로 채우면 됩니다). 만약 서버가 있는 PC(노트북)도 집/회사를 오간다면,
장소를 옮길 때마다 **🔔 자동수집 설정**에서 그 장소의 새 주소를 확인해서
MacroDroid의 URL을 그 장소용으로 바꿔줘야 합니다 - 매번 바꾸기 번거로우면 MacroDroid에서
"연결된 Wi-Fi 이름" 조건으로 매크로를 2개(집용/회사용) 만들어두는 방법도 있습니다.

## 지난 내역 백업 · 지나간/놓친 결제 한 번에 올리기

화면 아래 **📦 지난/누락 내역 백업 · 일괄 업로드** 카드에서 PC로 접속해서 쓰는 걸
추천합니다(카드사 홈페이지 다운로드도, 엑셀 확인도 PC가 훨씬 편합니다).

**① 카드사 엑셀을 그대로 올리는 방법 (추천)**

카드사 홈페이지/앱에서 "이용내역조회" 등으로 받은 엑셀 파일을 **변환하거나 손대지 않고
그대로** 업로드하면 됩니다. "이용일자/승인일자", "이용금액/승인금액" 같은 헤더를 자동으로
찾아서 인식하고, 카드번호 열이 있으면 뒤 4자리로 어떤 카드인지도 자동 매칭합니다.
다만 이 표에는 "어떤 혜택"인지는 없으므로, 업로드하면 알림 자동수집과 똑같이
**"받은 결제 알림" 목록에 쌓이고**, 앱에서 하나씩 혜택을 골라주면 완료됩니다.
날짜·금액 열을 못 찾으면 "카드사에서 받은 파일 원본 그대로 올려달라"는 안내가 뜹니다
(엑셀 위쪽에 안내문구가 섞여 있어도 표 자체만 찾으면 되니 그대로 올리면 됩니다).

**② 이 앱의 빈 양식을 직접 채우는 방법**

**빈 양식 받기**를 누르면 등록된 카드·혜택 이름이 미리 채워진 엑셀이 다운로드됩니다.
날짜/금액을 직접 알고 있고 어떤 혜택인지도 이미 정해서 채울 수 있다면, 이 양식에
채워서 올리면 배정 과정 없이 바로 사용내역으로 들어갑니다(카드명·혜택명은 정확히
일치해야 매칭되므로 이름 칸은 그대로 두는 걸 권장합니다).

**전체 내역 다운로드**는 지금까지 기록된 모든 사용내역을 엑셀로 받는 백업용입니다.

업로드하면 몇 건이 처리됐고 몇 건이 왜 스킵됐는지(날짜/금액 인식 실패 등) 바로
보여줍니다. **같은 파일을 두 번 올리면 내역이 중복으로 쌓이니 주의하세요.**

## 폰에서 접속하는 방법

1. **폰과 서버 PC를 같은 와이파이에 연결**합니다 (둘 다 같은 공유기에 붙어있어야 함,
   데이터망/LTE는 안 됩니다).
2. PC에서 `START.bat`을 실행하면 콘솔 창에 이렇게 뜹니다:
   ```
   폰에서 볼 때(같은 와이파이):   http://192.168.0.12:5050
   ```
   (숫자는 PC마다 다름) 이 주소를 그대로 적어둡니다.
   - 콘솔 창을 이미 닫았거나 주소를 놓쳤다면, PC에서 명령 프롬프트를 열고
     `ipconfig` 입력 → "IPv4 주소" 값을 확인하면 됩니다 (예: `192.168.0.12`).
3. **폰 브라우저(크롬 등)** 주소창에 `http://192.168.0.12:5050` 처럼 그 주소를
   그대로 입력해서 접속합니다.
4. 자주 쓸 거면 폰 브라우저에서 "홈 화면에 추가"를 해두면 앱처럼 바로 열 수 있습니다.

## 파일 구조

```
app.py              Flask 서버 (라우트 + 잔여혜택 계산 + 알림 자동수집 API)
models.py           SQLite 스키마 + 혜택 사이클(초기화 주기) 계산 + 알림 텍스트 파싱
templates/index.html
static/css/style.css
static/js/app.js
card_benefit.db      카드/혜택/사용기록 데이터 (최초 실행 시 자동 생성)
launcher.py, START.bat   Windows 더블클릭 실행용
```

## 데이터 백업 / 다른 PC로 옮기기

`card_benefit.db` 파일 하나만 복사하면 모든 카드/혜택/사용기록이 그대로 옮겨집니다.
