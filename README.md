# 이유마켓 CEO Margin Pro - 웹 대시보드

기존 PyQt5 데스크톱 프로그램(`app.py`)을 웹 기반 다크모드 대시보드로 이식한 버전입니다.
`기능명세서.docx`에 정리된 계산 로직(수수료 계산, 매입 매칭, 마진 포함 판정, 합배송 중복 방지 등)을
`calc_engine.py` 한 곳에만 구현해서, 대시보드 표 / 상단 실시간 합계 / 요약 리포트 / 캘린더가
전부 같은 계산 결과를 공유합니다. (원본에서 화면마다 계산을 따로 구현해 숫자가 어긋났던 문제의 재발 방지)

## 실행 방법

### Windows - 더블클릭으로 실행 (권장)

`실행하기.bat` 파일을 더블클릭하면 필요한 프로그램 설치 → 서버 시작 → 브라우저 열기까지 자동으로 됩니다.
(최초 1회는 설치 때문에 몇 초 걸릴 수 있어요) 새로 열리는 검은 창을 닫으면 프로그램이 종료됩니다.

### 직접 명령어로 실행

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속.

기존에 쓰던 `이유상점_데이터.db`(주문/매입/오너클랜 원본 데이터)가 이미 이 폴더에 포함되어 있어서
바로 대시보드에 데이터가 채워집니다. 다른 PC로 옮길 때는 이 `.db` 파일과 `fees_config.json`만
같이 복사하면 됩니다.

## 화면 구성

- **👑 요약 리포트** - 전체 기간 KPI 5종, 연/월/마켓 필터, 마켓별 요약표, 순수익 비중 도넛차트, 일별 매출/마진 캘린더
- **📊 통합 마진 대시보드** - 검색 + 연/월/마켓/HL주문건/미매입/합배송 필터, 24열 주문 목록(정렬 가능),
  행별 "마진포함"·"광고"(TOSS 전용) 체크박스 - 클릭 시 그 행과 상단 합계만 갱신됩니다(전체 표 다시 안 그림)
- **📥 데이터 업로드** - 다팔자/TOSS/오너클랜 엑셀 자동판별 업로드(드래그앤드롭), 다팔자·오너클랜 사이트
  바로가기 버튼(주소는 직접 설정), HL(수기 매입처) 텍스트 붙여넣기 매칭
- **⚙️ 수수료 설정** - 마켓별 수수료 6개 항목 편집/저장/초기화

## 엑셀 다운로드 자동화(로그인 자동화)에 대해

지금 버전은 "다팔자/오너클랜 사이트를 새 탭으로 열기 → 수동으로 엑셀 다운로드 → 대시보드에 업로드"까지가
자동화되어 있습니다. 로그인 자체까지 자동화(아이디/비번 저장 후 자동 로그인·다운로드)하려면 실제 사이트
화면 구조를 보면서 만들어야 하고, 계정정보를 어딘가에 저장해야 하는 보안 트레이드오프가 있어서 이번 1단계에는
포함하지 않았습니다. 필요하면 다음 단계로 이어서 만들 수 있습니다.

## 파일 구조

```
app.py            Flask 서버 (라우트만 담당)
calc_engine.py     계산 엔진 (단일 소스 - 수수료/매입매칭/마진판정)
parsers.py         엑셀 업로드 파싱 + HL 텍스트 파싱
templates/index.html
static/css/style.css
static/js/app.js
이유상점_데이터.db   주문/매입/오너클랜 데이터 (SQLite)
fees_config.json    마켓별 수수료 설정
settings.json        빠른 이동 링크 등 사용자 설정 (최초 저장 시 생성)
```
